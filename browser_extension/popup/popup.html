Gateway Allow/Block List
Off by default. When the whitelist is active, only gateways on the list may connect (empty list = deny all); when the blacklist is active, only gateways on the list are blocked. List changes only affect new connections; existing connections are not disconnected.
⚠️ High-Risk Action Confirmation
The Agent is requesting to perform an action that may cause irreversible consequences.
You can connect to multiple HaijunBot gateways simultaneously, each with an independent connection.
Login sessions are automatically reused from the HaijunBot web page already logged into in the browser; no need to manually fill in a Token.
Note: All gateways share the same set of browser tabs.
