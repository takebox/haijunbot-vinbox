# 9. Appendix

## 9.1 Complete Configuration Options List

The following are all configurable parameters in `~/.haijunbot/config.yaml` and their descriptions.

| Variable Name     | Default Value | Description                                                                                                                                                                                                                                                                                                    |
| ------------ | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ENV`        | `{}`   | Environment variable configuration, used to store sensitive information such as API Keys, e.g. `OPENAI_API_KEY`. API Key supports comma-separated multi-key format to enable round-robin, e.g. `OPENAI_API_KEY=key1,key2,key3`.                                                                                                                                                        |
| `llms`       | `{}`   | Reusable LLM configuration definitions, which can be referenced by name in `llm_groups`. Each configuration contains `platform` (platform name), `model` (model name), `max_input_token_count` (maximum input token count), `llm_config` (LLM-specific configuration parameters such as API key).                                                                               |
| `llm_groups` | `{}`   | Predefined LLM configuration groups, using the group name as key (object format). Each group must reference the configurations defined in `llms` via `normal_llm`, `cheap_llm`, `smart_llm`; directly defining parameters such as `platform`, `model`, `max_input_token_count` is no longer supported. Each group can optionally specify a fallback group via `fallback_group` (automatically switches and retries once when this group's models fail consecutively in non-interactive mode). |
| `llm_group`  | `""`   | Name of the LLM group to activate.                                                                                                                                                                                                                                                                                 |

**Note**: Directly defining parameters such as `platform`, `model`, `max_input_token_count` in `llm_groups` is no longer supported; you must reference the configurations defined in `llms` via `normal_llm`, `cheap_llm`, `smart_llm`.

The following is an example of a `llm_groups` configuration using the reference approach:

```yaml
llms:
  haijun-4-5:
    platform: openai
    model: haijun-opus-4-5-20251101
    max_input_token_count: 200000
    llm_config:
      openai_api_key: sk-xxx # Supports a single Key, comma-separated ("sk-xxx1,sk-xxx2"), or list (["sk-xxx1","sk-xxx2"]) format; automatically round-robins when multiple Keys are provided
      openai_api_base: https://api.openai.com/v1

llm_groups:
  haijun:
    normal_llm: haijun-4-5
    cheap_llm: haijun-4-5
    fallback_group: gpt # Optional: automatically switches to the gpt group when this group's models fail consecutively in non-interactive mode
  gpt:
    normal_llm: haijun-4-5
    cheap_llm: haijun-4-5

llm_group: haijun
```

When `llm_group: haijun` is set, HaijunBot will use `haijun-4-5` as the normal model and `haijun-4-5` as the cheap model. When the models in the `haijun` group fail consecutively (retries exhausted and still returning empty results), if in non-interactive mode and `fallback_group` is configured, HaijunBot will automatically switch to the `gpt` group and retry once; it does not switch in interactive mode or when `fallback_group` is not configured.
