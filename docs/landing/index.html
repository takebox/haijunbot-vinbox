Product Forms

Three Forms, One Consistent Experience

Whether you prefer the efficiency of CLI, the intuitiveness of Web, or the integrated experience of IDE, HaijunBot seamlessly fits into your workflow.

⌨️

CLI

The geek's choice. Launch with a single command, supports interactive dialogue, pipe composition, and script integration — built for efficiency-driven developers.

hqc haijunbot-quick-config — Quick LLM platform configuration
hca haijunbot-code-agent — Code analysis and generation
hcad haijunbot-code-agent-dispatcher — Code agent (dispatcher mode)
hjb haijunbot — General AI agent
hjbd haijunbot-agent-dispatcher — General agent (dispatcher mode)
hgc haijunbot-git-commit — Auto-generate commit messages
hgs haijunbot-git-squash — Commit history reorganization
hpm haijunbot-platform-manager — LLM platform management
hc2r haijunbot-c2rust — C-to-Rust migration suite
🌐

Web UI

Visual operation. Open in browser with no setup, multi-session management, real-time terminal, file browsing, supporting multi-node distributed collaboration.

# Master mode (main node)
haijunbot-service start --node-mode master

# Child mode (connects to main node)
haijunbot-service start --node-mode child --master-url ws://master:8000 --node-secret YOUR_SECRET

# Common environment variables
HAIJUNBOT_GATEWAY_HOST =127.0.0.1
HAIJUNBOT_GATEWAY_PORT =8000
HAIJUNBOT_FRONTEND_HOST =127.0.0.1
HAIJUNBOT_FRONTEND_PORT =5173
HAIJUNBOT_NODE_MODE =master/child
HAIJUNBOT_MASTER_URL =ws://master:8000
HAIJUNBOT_NODE_SECRET =your_secret
→ Gateway http://localhost:8000 | Frontend http://localhost:5173

Quick Start

Get Started in 30 Seconds

Run one command after installation to start AI-assisted development.

1

Install

One-click install, automatic environment setup

# Linux/macOS bash -c "$(curl -fsSL https://...install.sh)" # Windows PowerShell iex (New-Object Net.WebClient).DownloadString(...)
2

Quick Config

Run the configuration wizard, select LLM platform and enter API Key

hqc # Quick config
3

Start Collaborating

Select Agent mode and start development

hca # Code Agent
