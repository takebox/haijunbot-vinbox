# Tools and Efficiency Feature Index

## Use Cases

When you want to quickly determine which document in the "Tools and Efficiency" directory best suits your current problem — for example, to first see what tools are available, directly call a tool, organize long-term memory, manage methodologies, or add natural-language command assistance to your Shell — you can start with this index.

## Steps

1. First, based on what you currently want to accomplish, find the closest scenario in the categories below.
2. Then open the corresponding document and follow the steps in it.
3. If multiple draft feature points share the same document, it means these capabilities belong to the same continuous chain of operations in real use; the official manual adopts a merged-coverage approach.
4. If a draft capability does not have its own document, it does not necessarily mean it is missing; it may already have been merged into a document on the same topic, or deliberately omitted because its user value is low.

## Prompts and Feedback You Will See

- The documents in this directory mainly cover the following categories of capabilities:

  - Tool system command line
  - Git commit efficiency
  - Long-term memory organization and migration
  - Methodology import, export, and extraction
  - Rule index viewing
  - Smart Shell installation and command generation

- Most documents are written with the fixed structure "Use Cases / Steps / Prompts and Feedback You Will See / Notes".
- A few draft points are merged into the same document to avoid splitting continuous command chains too finely.

## Notes

- This directory mainly covers command-line capabilities, not Web page features.
- If you find that an item in the draft has no standalone document, you should first judge whether it has already been effectively covered by an existing document, rather than only checking whether the titles correspond one-to-one.
- For content that has low user value, is easily misleading, or is more like an internal mechanism description, the official manual deliberately omits it and will not force a document just to make up the numbers.
