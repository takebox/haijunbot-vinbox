# Adjusting the Sidebar and Floating Window Layout

## Use Cases

When you use the Agent list, terminal panel, and online editor together in the Web UI and want to rearrange the layout to better fit your screen size and the current task, you can use the sidebar width adjustment, floating window dragging, resizing, and maximizing features.

## Steps

### Adjusting the Agent Sidebar Width

1. Open the Agent sidebar on the left on desktop.
2. Move the mouse to the right edge of the sidebar.
3. Drag the edge to adjust the sidebar width.
4. After you release the mouse, the new width is remembered.

### Adjusting the Terminal Panel

1. Open the standalone terminal panel.
2. On desktop, press and drag the top title bar of the panel to move it.
3. Drag the resize areas on the panel's edges or corners to adjust the terminal panel size.
4. Click the maximize button at the top-right of the panel to toggle between "Maximize" and "Restore".

### Adjusting the Editor Panel

1. Open the online editor.
2. On desktop, press and drag the top title bar of the editor to move it.
3. Drag the resize areas on the edges or corners to adjust the editor size.
4. Click the maximize button at the top-right of the editor to toggle between "Maximize" and "Restore".

### Opening or Closing Related Panels

1. To show or hide the Agent sidebar, terminal panel, or editor panel, prefer the corresponding buttons on the page.
2. After opening the terminal or editor, you can continue to drag, resize, or maximize the window.
3. To close a pop-up or a temporary panel, use the close button on the page together with the Esc key.

## Feedback You Will See

- The top-right of the terminal and editor panels shows a maximize or restore button.
- The floating window you are currently operating is brought to the front so you can keep using it easily.
- After adjusting on desktop, when you reopen the page the system usually keeps your previous window position, size, and sidebar width.
- On mobile, the editor is closer to a full-screen view, and the sidebar usually fills the full screen width instead of keeping the free-dragging experience of desktop.
- When you press Esc, if there is a settings window, directory picker, or session restore window open, the page closes those pop-ups first.

## Notes

- Dragging to resize the sidebar is mainly a desktop capability; mobile usually does not offer the same width adjustment.
- Dragging and resizing the terminal and editor are also mainly for desktop; mobile favors overlay-style presentation.
- This document only covers the confirmed button, dragging, resizing, maximizing, and Esc behaviors; if your environment has additional shortcuts, follow what the page actually does.
- Adjusting the layout only changes the interface display; it does not modify the content of Agents, files, or the terminal.
