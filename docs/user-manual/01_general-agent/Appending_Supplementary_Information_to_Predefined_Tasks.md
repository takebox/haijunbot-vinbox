# Appending Supplementary Information to Predefined Tasks

## When to Use

When you have already selected a task from the predefined task list, but this execution has additional background, goals, constraints, or input materials, you can continue to append descriptions before the formal execution.

## Steps

1. First select a predefined task.
2. After selecting, the system asks: `Do you want to add supplementary information for this task?`
3. If you choose yes, the system opens a multiline input box and prompts: `Please enter supplementary information`
4. In the input box, write the supplementary requirements specific to this execution.
5. After writing, press `Ctrl+J` or `Ctrl+]` to submit; the system merges the predefined task and the supplementary information and executes them together.

## Prompts and Feedback You Will See

- If you choose not to supplement, the system continues directly with the original task.
- If you choose to supplement, you will first see: `Please enter supplementary information`
- If you supplemented content, these supplementary notes, together with the predefined task, become part of the current task input.
- The supplementary information input method is the same as ordinary multiline input, using the same submit and cancel keys.

## Notes

- It is best to write information unique to this task as the supplementary content, and not repeat content already in the template.
- If the supplementary notes conflict with the original task's goals, the final result may be unstable.
- If you cancel the input during the supplementation stage, you will usually return to the result of not supplementing or end the current append flow.
