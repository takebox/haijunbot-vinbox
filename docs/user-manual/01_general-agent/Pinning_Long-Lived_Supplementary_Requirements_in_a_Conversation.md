# Pinning Long-Lived Supplementary Requirements in a Conversation

## When to Use

If you want certain requirements to stay in effect in subsequent sessions, such as a fixed output format, a unified language style, or work constraints to be followed long-term, you can pin this content down to avoid entering it repeatedly.

## Steps

1. First enter `'<Pin>'` in the current conversation input box.
2. Immediately after it, write the supplementary requirements you want to keep long-term, such as a fixed output format, language style, or long-term constraint.
3. Press `Ctrl+J` or `Ctrl+]` to submit.
4. After submitting, the system saves the content after `'<Pin>'` as pinned content, which stays in effect when you continue executing other tasks later.

## Prompts and Feedback You Will See

- After a successful pin, the system prompts something like: `📌 Pinned content: ...`, and displays the first part of your pinned content.
- This kind of pinned content does not just affect the current single input; it continues to participate in subsequent conversations.
- Afterwards you do not need to repeatedly enter the same set of supplementary requirements every round.

## Notes

- After `'<Pin>'` you should write stable, long-term applicable requirements; do not stuff in temporary notes that are only valid for a single task.
- If you pin content multiple times in a row, the system continues to append rather than automatically replacing the old content.
- As the pinned content grows, also be wary of it imposing unnecessary constraints on subsequent tasks.
