# Letting the System Decide Whether to Save Long-Term Memory at Task End

## When to Use

When you want the system to decide for itself whether there is experience, preference, or project information worth saving long-term in this task, rather than manually deciding whether to remember each time, you can use automatic memory decision-making.

## Steps

1. First use a session or startup mode that supports the memory capability.
2. Execute and complete the task normally.
3. At task end, the system automatically reviews this task and decides whether there is information worth saving.
4. If it judges there is value, it automatically enters the memory-saving flow; if not, it ends directly without forcing a save.

## Prompts and Feedback You Will See

- The system may give memory-related suggestions, for example suggesting saving key information before analysis.
- If automatic saving succeeds, it displays: `✅ Valuable information has been automatically saved to the memory system`
- If the system judges there is no information worth saving, it does not force a save.

## Notes

- Automatic decision-making depends on the current entry point having the memory capability.
- This capability is suitable for distilling long-term reusable information, not for storing all one-off content.
- If you have important content you clearly want to keep, it is still recommended to save it manually and not rely entirely on automatic decision-making.
