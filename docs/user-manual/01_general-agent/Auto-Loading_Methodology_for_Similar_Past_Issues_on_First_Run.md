# Automatically Loading the Methodology for Similar Past Issues on the First Run

## When to Use

When you start the current task for the first time and want the system to automatically refer to experience accumulated from handling similar issues in the past, rather than exploring from scratch every time, you can enable the methodology capability.

## Steps

1. First enter a startup mode or session with the methodology capability turned on.
2. Enter the current task normally and submit it in the usual way.
3. In the first-run stage, the system automatically searches for the methodology of similar past issues based on the current task content.
4. If suitable experience is found, the system automatically brings this content into the current task environment.

## Prompts and Feedback You Will See

- Methodology loading happens at the start of the task, not after the task ends.
- The system automatically retrieves similar experience based on the current task content, without you needing to write search terms first.
- After successful loading, subsequent execution automatically refers to this part of the historical experience.

## Notes

- This capability depends on methodology already being enabled at the current entry point; if it is not enabled, it will not load automatically.
- Methodology is suitable for reference; it does not mean you must copy it item by item.
- If the current task differs greatly from the historical experience, the reference value of the methodology may be limited.
