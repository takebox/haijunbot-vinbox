# Getting Support

Encountering a problem or need help? The following channels are listed in order of recommendation.

## Quick Start

- First read the "Quick Start" and "Common Commands" sections of [README.md](README.md).
- Check `haijunbot --help` for command-line help.

## Troubleshooting

- **Search existing issues**: Search [Issues](https://github.com/takebox/HaijunBot/issues) to see whether the same problem already exists, to avoid duplicate questions.
- **Check the documentation**: The project documentation site (GitHub Pages) and the `docs/` directory contain explanations of architecture design, deployment, multi-user configuration, and more.

## Where to Ask

- **Bug reports / feature suggestions**: Submit in [Issues](https://github.com/takebox/HaijunBot/issues). When reporting a bug, please include:
  - Operating system and Python version
  - HaijunBot version (the `__version__` in `src/haijunbot/__init__.py`)
  - Steps to reproduce, expected behavior, and actual behavior
  - Relevant logs or error messages
- **Security vulnerabilities**: Please use the private reporting channel in [SECURITY.md](SECURITY.md), and **do not** disclose them in public Issues.
